用手机或电脑写文章、上传照片，保存后自动同步到 GitHub。

打开图文编辑器

  1. 首次使用：通过 GitHub 登录，并授权 Pages CMS 访问 Luanxing.github.io 仓库。
  2. 选择仓库 Luanxing/Luanxing.github.io 和 master 分支，再打开「文章」。
  3. 新文章默认是草稿。想发布时关闭「草稿」并保存，等待 GitHub Actions 部署完成。

正文支持插入图片和切换 Markdown 源码。照片请使用 JPG、PNG 或 WebP 等格式，HEIC 请先转换。

仓库是公开的，草稿源文件和上传图片也可以被访问。
